# 悬浮音乐播放器设计

## 目标

为现有 H5 车队网站增加背景音乐，不改变页面布局或现有功能。使用用户提供的 FLAC 音乐和头像图片。

## 交互

- 页面加载后立即尝试有声自动播放，并循环播放。
- 若浏览器阻止自动播放，在用户第一次触摸或点击页面后尝试开始播放。
- 圆形头像固定吸附在页面右侧，不参与正文排版。
- 单击头像：播放时暂停，暂停时继续。
- 长按头像 650 毫秒：停止音乐、归零进度并关闭控件；刷新页面后恢复。
- 播放时头像顺时针匀速旋转；暂停时停在当前角度。

## 视觉

- 使用用户提供的方形头像裁切为圆形。
- H5 尺寸约 56px，桌面端约 62px；保留安全区和右侧间距。
- 使用现有蓝色信号色描边和阴影，保持当前赛车俱乐部视觉风格。
- 不增加可见操作说明、弹窗、进度条、音量条或歌名面板。

## 实现边界

- 新建独立 `MusicPlayer` React 组件，由 `App` 在首页和相册页之外的站点壳层中挂载。
- 音频和头像作为静态资源放入 `public`，使用简短 ASCII 文件名。
- 控件提供随播放状态变化的无障碍名称，并在卸载时移除事件监听和定时器。
- 不引入新依赖，不增加全局状态管理或后台接口。

## 验证标准

- 自动播放成功时头像旋转，失败时首次页面交互可启动音乐。
- 单击可以稳定地暂停和继续，长按可以关闭。
- 关闭后音频停止且控件消失，刷新后恢复。
- 390px H5 和桌面视口没有页面横向溢出，不遮挡关键页面文字。
- 自动化测试、生产构建和浏览器控制台检查通过。
