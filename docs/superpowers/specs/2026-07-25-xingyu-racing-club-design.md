# ⁢⁣ˣʸ༩·星⁡⁠屿 车队内部荣誉站设计文档

## 目标

从 0 到 1 实现一个手机优先的车队内部网站，用于展示车队荣誉、核心成员、完整阵容、积分榜和资讯动态。

网站不是对外招商官网，也不是带后台的管理系统。第一版目标是用最少代码做出可用、可替换内容的内部展示站。

## 已确认需求

- 车队名称：`⁢⁣ˣʸ༩·星⁡⁠屿`
- 展示方式：完整保留特殊符号作为主标题。
- 视觉方向：高级俱乐部感。
- 主要用户：车队内部成员。
- 主要设备：手机。
- 成员规模：30 人。
- 首页核心成员：8 人。
- 内容管理：配置文件，不做后台。
- 素材状态：当前没有真实全家福、成员照和高光视频，第一版使用可替换占位素材。
- 资讯区含义：资讯动态，包括比赛动态、公告、战报等。

## 页面结构

首页采用单页结构，按手机端阅读顺序组织：

1. 首屏荣誉区

   - 展示车队全家福占位图。
   - 覆盖完整车队名 `⁢⁣ˣʸ༩·星⁡⁠屿`。
   - 展示简短赛季身份文字，例如 `RACING CLUB / 2026 SEASON`。

2. 核心数据区

   - 展示车队车队排名、活跃排名、成员数量和编外成员。
   - 数据来自配置文件。

3. 核心成员区

   - 展示 8 位核心成员（一名队长，4名副队，3名精英）。
   - 每位成员包含姓名、编号或角色、占位形象照、高光视频入口。
   - 点击成员卡片打开视频弹窗。

4. 完整阵容区

   - 展示 30 人完整阵容。
   - 使用紧凑卡片，避免首页过长。
   - 可展示姓名、编号、角色和积分摘要。

5. 积分榜区

   - 展示排名、成员、积分。
   - 手机端表格保持可读，不做复杂筛选。

6. 资讯动态区

   - 展示比赛动态、公告、战报。
   - 第一版使用配置文件静态维护。

## 视觉原则

- 手机优先，一屏只突出一个重点。
- 采用“午夜银赛道”方向：炭黑、骨白、金属银为主，信号红仅用于排名和交互重点。
- 版式参考赛事年鉴和汽车杂志，用不对称构图、超大编号和留白建立层级。
- 不使用霓虹描边、彩色光球、复杂渐变和夸张电竞装饰。
- 成员照片与视频是主视觉资产，当前用统一风格占位。
- 积分榜保持专业、清晰，不抢首屏。

## 视觉改版细节

### 首屏

- 首屏保持全宽、接近一屏高度，使用赛道或车库材质图片作为临时背景，不伪造车队成员形象。
- 完整车队名位于视觉下半部，标题、赛季标识和口号分层进入。
- 使用细线坐标、赛季编号等少量赛事信息增强身份感，避免堆叠装饰。

### 内容层级

- 核心数据从四张同质卡片改为连续数据带，数字是第一视觉重点。
- 8 位核心成员使用纵向车手档案卡；编号作为背景视觉，姓名、角色和播放入口固定在底部。
- 30 人阵容使用紧凑名册，不与核心成员争夺视觉注意力。
- 积分榜前三名强化名次和分数，其余行保持统一密度，整体接近赛事计时牌。
- 资讯动态使用纵向时间线和日期分组感，减少独立卡片堆叠。

### 动效

- 页面进入时，首屏背景遮罩揭幕，标题和赛季文字依次进入。
- 内容区进入视口时做一次短距离上移和淡入，列表子项使用轻微错峰。
- 核心成员卡片在支持悬停的设备上提供图片缩放、边框亮度和播放按钮位移反馈。
- 视频弹窗使用背景淡入和内容缩放进入；关闭时不增加额外等待。
- 动效仅使用 CSS 和浏览器原生 `IntersectionObserver`，不引入动效依赖。
- 系统开启 `prefers-reduced-motion: reduce` 时关闭位移、缩放和错峰动画。

### 素材策略

- 首屏增加一张可替换的本地赛道材质图，作为真实全家福到位前的过渡素材。
- 成员没有真实头像时使用统一编号占位，不生成虚构人物肖像。
- `teamData.js` 继续作为图片和视频地址的唯一配置入口。

## 技术方案

使用 Vite + React 实现单页应用。

建议文件结构：

```text
src/
  App.jsx
  main.jsx
  data/
    teamData.js
  components/
    Hero.jsx
    StatsBar.jsx
    FeaturedMembers.jsx
    Roster.jsx
    Leaderboard.jsx
    NewsFeed.jsx
    VideoModal.jsx
  styles/
    global.css
```

`teamData.js` 作为第一版内容配置中心，包含：

- 车队基础信息。
- 核心数据。
- 核心成员 8 人。
- 完整成员 30 人。
- 积分榜。
- 资讯动态。
- 图片和视频占位地址。

## 交互

- 点击核心成员卡片打开视频弹窗。
- 视频弹窗支持关闭。
- 视频弹窗支持点击背景和按 `Escape` 关闭，并在打开时阻止背景滚动。
- 没有真实视频时显示占位提示。
- 页面导航使用自然滚动，不做复杂路由。

## 非目标

第一版不做：

- 登录系统。
- 后台管理。
- 数据库。
- 支付、报名、评论。
- 多页面 CMS。
- 自动抓取积分。

这些功能只有在内部站稳定后再评估。

## 验证标准

第一版完成后需要验证：

- 手机宽度下没有横向滚动。
- 车队名称完整显示。
- 8 位核心成员能正常渲染。
- 30 人完整阵容能正常渲染。
- 成员卡片点击后能打开和关闭视频弹窗。
- 积分榜在手机端可读。
- 资讯动态从配置文件渲染。
- 修改配置文件后页面内容能同步变化。
- 首屏、成员区、积分榜和资讯区具有明确且不同的视觉层级，不再表现为同质卡片集合。
- 页面进入、滚动露出和视频弹窗具备可感知但克制的动效。
- 开启减少动态效果后，页面内容立即可见且交互完整。
- 手机宽度下动效不引发布局跳动，桌面端悬停反馈不改变卡片尺寸。
