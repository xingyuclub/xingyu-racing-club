# 星屿车队 H5 蓝白官方风格改造设计

## 目标

在现有星屿车队 H5 中，仅调整视觉风格和动效表现，使页面更接近 QQ 飞车手游移动端官网的蓝白、轻量、官方运营页气质。

本次不改变页面布局顺序，不增减功能，不新增模块，不改变数据结构。现有 Hero、数据条、队员风采、相册空间、完整阵容、积分榜、资讯动态、相册页和弹窗能力全部保留。

## 已确认方向

- 视觉方向：蓝白官方 H5 风。
- 参考特征：QQ 飞车手游移动端官网的白底、腾讯蓝、浅灰分割线、胶囊标签、轮播圆点胶囊态、轻快滚动动效。
- 约束：只做皮肤层和动效层改造。
- 不做：新增下载栏、导航 Tab、快捷入口宫格、额外内容模块、额外页面或第三方依赖。

## 改造范围

主要改动集中在 `src/styles/global.css`。

允许的少量代码改动：

- 如样式需要，可给已有元素补充不影响行为的 className。
- 不改组件数量，不改组件顺序，不改数据字段含义。

不改动：

- `teamData.js` 的业务数据结构。
- 相册两级导航逻辑。
- 队员风采轮播数量和交互逻辑。
- 视频弹窗、照片弹窗、积分明细弹窗功能。
- 首页模块顺序。

## 视觉系统

### 色彩

将当前“午夜银赛道”的炭黑、信号红体系，切换为更接近手游官网的蓝白体系：

- 页面背景：白色和极浅蓝灰。
- 主色：腾讯蓝系，重点使用 `#296aca`、`#4690ff`、`#6798fc`。
- 文字：深蓝灰和中性灰，例如 `#2f3d5c`、`#535455`、`#838486`。
- 分割线：浅灰蓝，例如 `#d8e0ee`、`#edf2f8`。
- 强调：使用亮蓝，不继续使用红色作为主强调。

### 版式质感

- 页面保持手机优先，但桌面预览仍需要居中和可读。
- 模块之间使用浅灰分割线和留白，不使用大面积暗色卡片。
- 模块标题使用“中文粗标题 + 英文小字”的官方资讯站样式。
- “更多”“查看”“返回”等轻操作按钮使用蓝色小按钮或蓝色文字按钮。
- 分类信息使用蓝色圆角胶囊标签。

### 图片呈现

- Hero 保留现有图片，不替换素材。
- Hero 遮罩从深黑压暗改为蓝色渐变和浅亮遮罩，使首屏更接近手游 KV。
- 相册和成员图片边框从深色线条改为浅灰蓝边框。
- 图片卡片底部仍可保留渐变标题条，但透明度和颜色改成更轻的蓝黑遮罩。

## 动效系统

### 页面进入

- 首屏保留短暂进入动效，但去掉深色幕布揭幕感。
- Hero 背景使用轻微放大进入，文字使用上移淡入。
- 动效节奏更轻快，避免厚重赛道杂志感。

### 滚动露出

- 继续使用现有 `IntersectionObserver`。
- 内容区进入视口时做短距离淡入上移。
- 列表子项保留轻微错峰，但时间缩短，整体更像移动端 H5。

### 轮播与圆点

- 队员风采 3D 轮播逻辑保留。
- 圆点从深色红色状态改为浅蓝灰默认、亮蓝激活。
- 激活圆点拉长为胶囊形态，呼应 QQ 飞车手游官网特色区轮播。
- 卡片 hover 和 active 状态使用蓝色边框、轻微上浮和柔和蓝色阴影。

### 弹窗

- 遮罩保留全屏固定层，但背景从纯黑压暗调整为深蓝半透明。
- 弹窗主体改为白底或近白底，顶部使用蓝色强调线。
- 打开时使用淡入和轻微缩放，不增加关闭等待。

### 减少动态效果

- 保持现有 `prefers-reduced-motion: reduce` 策略。
- 减少动态效果开启时，内容立即可见，轮播和弹窗仍可操作。

## 模块级改造

### Hero

- 保留全屏大图和现有文字层级。
- 文字颜色改为白色，配合蓝色渐变遮罩保证可读。
- 边框和坐标线装饰从红色赛车感改为蓝色官方 H5 感。

### StatsBar

- 从暗色数据条改为白底数据卡。
- 顶部强调线改为蓝色。
- 数字使用深蓝灰，标签使用中性灰。
- 单身成员男女数字继续按现有结构显示。

### FeaturedMembers

- 轮播结构和数量不变。
- 卡片底色改为白色，图片区域保留深浅渐变。
- 编号和角色信息用蓝色体系。
- 播放按钮改为蓝色描边圆形按钮，hover 时填充蓝色。

### GalleryPreview 与 AlbumPage

- 保持现有“一大四小”和相册文件夹两级结构。
- 图片卡片改为浅边框、轻阴影。
- 标题条改为轻量蓝黑渐变。
- 返回按钮和查看更多按钮使用蓝色文字/描边按钮。

### Roster 与 Leaderboard

- 名册和积分榜保持紧凑结构。
- 行分割线改为浅灰蓝。
- 前三名使用浅蓝背景和左侧蓝色竖线强调。
- 排名数字使用深蓝或亮蓝，不使用红色。

### NewsFeed

- 保持时间线信息结构。
- 时间点颜色改为蓝色。
- 新闻类别显示为蓝色胶囊标签。
- 资讯内容卡减少暗色感，改为白底轻分割。

## 非目标

本次不做以下内容：

- 不增加顶部下载栏。
- 不增加首页导航 Tab。
- 不增加快捷入口宫格。
- 不新增视频中心、图鉴、社区等模块。
- 不引入 Swiper、jQuery、Zepto 或其他第三方库。
- 不替换真实图片素材。
- 不改变现有测试覆盖的行为。

## 验证标准

- 首页模块顺序与当前版本一致。
- 功能数量与当前版本一致。
- `teamData.js` 数据结构不因本次改造发生业务变化。
- 页面主色从深色红色体系切换为蓝白官方 H5 体系。
- 390×844 手机视口下无横向滚动、文字遮挡或按钮溢出。
- 1280×900 桌面视口下内容居中、卡片比例正常。
- 队员风采轮播、相册两级导航、照片弹窗、视频弹窗、积分明细弹窗仍可用。
- `prefers-reduced-motion: reduce` 下内容立即可见，交互不丢失。
- `npm test -- --run` 通过。
- `npm run build` 通过且无 CSS 语法警告。
