# 星屿车队相册、队员风采与积分明细设计

## 目标

在现有车队内部荣誉站中增加四项能力：车队相册、3D 队员风采轮播、单身成员男女统计、积分明细表。继续保持手机优先、配置文件维护和“午夜银赛道”视觉，不增加后台服务、数据库或第三方轮播依赖。

## 设计选择

轮播曾比较平面横滑、外部轮播库和原生 3D Coverflow 三种方案。最终确认原生 3D Coverflow：能呈现中间前置、两侧后退旋转的立体关系，同时保持依赖最少并能精准适配现有视觉。

相册曾比较首页完整瀑布流、首页折叠区和首页精选加独立相册页三种方案。最终确认首页精选加独立相册页，避免未来大量照片拖长首页。

## 1. 队员风采 3D 轮播

- 原“核心阵容”标题改为“队员风采”。
- 展示 8 位核心成员，数据继续来自 `teamData.featuredMembers`。
- 中间当前卡片位于最前方并放大；相邻卡片向后旋转、缩小；更远卡片进一步后退并降低透明度。
- 自动轮播默认每 4 秒切换一次。
- 支持触摸和鼠标左右拖动，水平位移超过 45 像素后切换一位。
- 用户开始拖动时暂停自动轮播，切换完成后重新计时。
- 轮播底部固定显示 8 个圆点，与 8 位成员按数组顺序一一对应。
- 当前圆点使用加长状态；自动轮播、拖动和点击圆点后都必须同步更新。
- 点击任意成员卡片打开该成员的视频弹窗；存在视频地址时自动播放。
- 没有视频时继续显示素材待替换提示。
- 系统开启减少动态效果时取消自动轮播和过渡动画，但手动切换、圆点和视频入口保持可用。

## 2. 相册空间

### 首页精选

- 首页新增“相册空间”，位置放在队员风采之后、完整阵容之前。
- 固定展示配置数组中的前 5 张照片。
- 布局保持已确认结构：桌面端 1 张大图加 4 张小图，手机端 1 张横向大图加 2×2 小图。
- 每张照片展示标题；点击打开大图预览。
- 区块下方提供“查看更多相册”按钮。

### 独立相册页

- 点击“查看更多相册”进入独立相册视图，不引入路由依赖。
- 使用 URL Hash `#album` 标记相册视图，使刷新后仍能停留在相册页。
- 相册页展示全部配置照片，并提供返回首页按钮。
- 相册使用响应式网格，照片数量可以持续增加。
- 点击任意照片打开大图预览，支持关闭按钮、点击遮罩和 `Escape` 关闭。

### 照片存储与配置

- 照片文件存放在 `public/images/album/`。
- `teamData.gallery` 保存照片元数据：`id`、`src`、`title`、`date` 和 `alt`。
- 新增照片时只需把文件放入相册目录并在配置数组追加一项。
- 第一版不做网页上传、用户文件写入、数据库和云存储；真实上传后台单独规划。
- 当前没有真实相册素材时使用本地占位图片路径和可读替代文字，不能伪造真人照片。

## 3. 单身成员统计

- 核心数据区第四项由“编外成员”改为“单身成员”。
- 配置结构为：

```js
{
  label: '单身成员',
  value: {
    male: 12,
    female: 8,
  },
}
```

- 页面显示“男 12”和“女 8”，两个数字均从配置读取。
- 其余三项核心数据和布局不变。

## 4. 积分明细表

- 积分榜标题区域增加“查看具体分数”按钮，使用表格图标加文字。
- 点击后打开积分明细弹窗。
- 明细数据来自 `teamData.scoreDetails`，每行包含：排名、成员、活跃分、赛事分、出勤分和总分。
- 总分与首页积分榜分数保持一致，避免同一成员出现两套总分。
- 桌面端直接显示完整表格；手机端允许表格区域横向滚动，弹窗本身不能超出视口。
- 弹窗支持关闭按钮、点击遮罩和 `Escape` 关闭，并在打开时锁定页面滚动。

## 组件边界

- `FeaturedMembers.jsx`：3D 轮播状态、自动切换、拖动和圆点。
- `GalleryPreview.jsx`：首页 5 张精选与“查看更多”命令。
- `AlbumPage.jsx`：完整相册视图。
- `PhotoModal.jsx`：单张照片大图预览。
- `Leaderboard.jsx`：榜单和打开明细表命令。
- `ScoreDetailsModal.jsx`：配置式积分表。
- `VideoModal.jsx`：成员视频自动播放和现有关闭行为。
- `teamData.js`：成员、相册、单身人数和积分明细唯一配置源。
- `App.jsx`：首页/相册视图与三个弹窗的选中状态。

## 错误与空状态

- `gallery` 为空时，相册区显示“相册照片待添加”，不渲染空网格。
- 图片加载失败时保留标题和占位背景，不出现破图图标。
- `scoreDetails` 为空时，按钮仍可打开弹窗并显示“积分明细待更新”。
- 视频地址为空时维持现有占位提示。

## 验证标准

- 页面标题显示“队员风采”，不再显示“核心阵容”。
- 轮播含 8 张成员卡和 8 个对应圆点。
- 自动轮播、点击圆点和左右拖动都会同步卡片与圆点。
- 点击成员卡后打开对应视频，真实视频地址存在时启用自动播放。
- 首页相册恰好显示 5 张精选照片。
- “查看更多相册”进入 `#album` 相册页，刷新和返回首页行为正确。
- 单身成员显示可配置的男女两项人数。
- “查看具体分数”打开配置式积分明细表。
- 三类弹窗都能通过按钮、遮罩和 `Escape` 关闭。
- 390×844 和 1280×900 下没有页面横向溢出或文字遮挡。
- 减少动态效果下不自动轮播，所有内容和交互仍可用。
