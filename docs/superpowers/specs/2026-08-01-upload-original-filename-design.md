# 后台上传字段显示原始文件名设计

## 目标

后台各上传字段在已上传素材路径下方显示用户上传前的原始文件名，不再展示完整 `/uploads/...` 路径；保持现有 UUID 防冲突机制和公开页面素材 URL 行为不变。

## 存储规则

- 新上传文件的服务端文件名改为 `<uuid>--<安全原始文件名>`。
- 保留原始扩展名和可安全使用的中文、空格等字符。
- 去除路径信息、控制字符和 Windows 文件名禁用字符，并限制文件名长度。
- UUID 仍保证同名文件不会互相覆盖。
- 上传响应和配置继续只保存 `path`，不增加业务配置字段或额外元数据文件。

## 显示规则

- `UploadField` 从配置路径中取最后一段文件名。
- 新格式文件显示 `--` 后的原始文件名。
- 旧 UUID 文件显示当前 UUID 文件名，保证已有素材仍可识别。
- 不显示 `/uploads/` 路径前缀。
- 头像、视频、首页媒体、备用图、新闻图片、相册和音乐等使用 `UploadField` 的位置统一生效。

## 兼容与错误处理

- 现有 UUID 文件不重命名，也不尝试恢复已经丢失的原名。
- 文件 MIME 与扩展名校验、图片 10MB 限制和总上传 200MB 限制保持不变。
- 素材删除继续使用实际服务端文件名，不受显示名称影响。
- 原始文件名清理后为空时，回退为 `file<扩展名>`。

## 验证标准

- 服务端测试覆盖新存储名包含 UUID 与安全原名、路径字符清理和同名不覆盖。
- 前端测试覆盖新格式显示原名、旧格式显示 UUID、完整路径不再可见。
- `npm test -- --run` 与 `npm run build` 通过。
- 后台实际上传后，红框位置显示原始文件名，刷新页面后仍保持。
