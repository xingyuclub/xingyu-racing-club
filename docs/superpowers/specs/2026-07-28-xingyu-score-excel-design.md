# 星屿积分 Excel 维护设计

## 状态

- 设计方向已由用户确认
- 本设计作为配置后台中“每日成绩”模块的补充约束
- 旧版周表仅用于参考字段和表格样式，不要求直接导入

## 1. 目标与边界

管理员可以在 `/admin` 的“星屿积分榜”模块中，以接近 Excel 的表格方式快速维护每日积分，也可以下载模板、上传 Excel 批量导入、导出当前积分数据。保存后，前端刷新即可在现有日期积分查询弹窗中按日期查看对应数据。

第一版按自然日保存积分，不再以周一到周日横向展开。第一版不解析旧版周表，也不支持任意表头映射。

## 2. 每日数据模型

运行时配置继续使用 `dailyScores`，每个日期一条记录：

```js
{
  date: '2026-07-28',
  rows: [
    {
      id: 'member-01',
      teamRace: [3, 2, 5],
      openRace: [1, 3, 2]
    }
  ]
}
```

成员配置增加 `basePoints`，表示开始使用每日明细前的期初累计积分。`weekday`、成员姓名、当日得分、累计总分和前端使用的当前积分均为派生字段，不在每日成绩中重复维护：

- `weekday`：根据 `date` 自动生成。
- 成员姓名：根据成员 ID 从 `roster` 读取。
- 当日得分：六局分数求和。
- 累计总分：期初积分加上截至当前日期的全部当日得分。
- 首页积分榜：按最新累计总分排序，并展示最新累计积分。

## 3. Excel 模板

Excel 包含两张工作表。

`积分明细` 使用纵向明细表，每行代表“某位成员在某一天的成绩”。固定列为：

| 日期 | 队员编号 | 队员昵称 | 队内赛1 | 队内赛2 | 队内赛3 | 开黑赛1 | 开黑赛2 | 开黑赛3 | 当日得分 | 累计总分 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |

其中：

- `日期`、`队员编号`、六局分数为可编辑输入。
- `队员昵称`用于人工核对，导入时以队员编号关联成员。
- `当日得分`和`累计总分`在导出文件中使用公式生成，导入时忽略用户填写值并由系统重新计算。
- 日期保存为真正的 Excel 日期值，显示格式为 `yyyy-mm-dd`。
- 分数必须是大于或等于 0 的有限数字；空白局数按 0 处理。

`队员期初积分` 每名成员一行，固定列为 `队员编号`、`队员昵称`、`期初积分`。期初积分是开始录入第一天前已有的累计积分，用于延续旧积分，不代表周数据。队员昵称用于核对，导入仍以队员编号关联。

后台提供三个操作：下载空白模板、导入 Excel、导出当前数据。导出的文件与模板使用同一列结构，可修改后再次导入。

## 4. 后台编辑与导入规则

后台“每日成绩”模块以可编辑表格展示数据，列结构与 Excel 保持一致。管理员可以直接新增、修改和删除明细行，也可以上传 `.xlsx` 文件。

导入流程：

1. 解析固定工作表和固定表头。
2. 校验日期、成员编号、成员关联和六局分数。
3. 以 `日期 + 队员编号` 作为积分明细唯一键，并以 `队员编号` 作为期初积分唯一键，拒绝文件内重复记录。
4. 生成导入预览，显示新增、更新、错误数量。
5. 用户确认后，将 Excel 中出现的日期整体覆盖；未出现日期的数据保持不变。期初积分表中的成员只更新对应成员的 `basePoints`。
6. 导入只更新后台草稿，管理员点击“保存配置”后才写入运行时 JSON。

出现任一错误时不应用导入结果。错误信息必须包含工作表、Excel 行号和字段名称。空文件、缺少工作表、错误表头、无效日期、未知成员、重复记录、负数或非数字分数和期初积分均视为错误。

## 5. 前端展示

前端保留现有“查找 -> 日期积分查询”流程：

- 日历中有积分数据的日期继续显示可用状态。
- 点击日期后展示队员、队内赛三局、开黑赛三局、当日得分和累计总分。
- 无记录日期继续显示“当日暂无积分记录”。
- 日期标题中的星期根据日期自动生成，不依赖后台或 Excel 手填。
- 首页星屿积分榜使用按日期计算后的最新累计总分。

## 6. 技术边界

- 浏览器端负责解析和生成 Excel，避免为模板下载和导入新增服务端文件存储接口。
- 使用成熟的 Excel 库处理 `.xlsx`，不使用 CSV 或手写二进制解析。
- 服务端仍只负责校验并保存统一的运行时 JSON。
- Excel 文件不上传到素材目录，也不在服务端长期保存。

## 7. 测试与验收

- 模板包含固定表头、日期格式和计算公式。
- 模板包含队员期初积分表，并能延续启用后台前的累计积分。
- 导出的数据可重新导入并还原相同的每日成绩。
- 合法文件可生成正确的新增和更新预览。
- 错误表头、重复日期成员、未知成员、无效日期和非法分数会被拒绝。
- 导入覆盖文件中出现的日期，不删除其他日期。
- 直接编辑表格与 Excel 导入得到相同的数据结构。
- 前端按日期展示六局成绩、当日得分和累计总分。
- 首页排行榜使用最新累计总分排序。
- `npm test`、`npm run build` 通过，并完成手机与桌面浏览器验证。
