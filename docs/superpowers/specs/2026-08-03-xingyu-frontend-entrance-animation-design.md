# 星屿车队前台全模块入场动画设计

日期：2026-08-03

## 背景

公开前台已有部分首页区块使用 `data-reveal` 和 `useRevealOnScroll` 做滚动淡入，但首屏、相册页、音乐浮窗和公开弹窗尚未统一接入。用户希望所有公开前台模块拥有一致的入场动画，同时不能破坏现有轮播、阵容圆柱滚动、弹窗交互和减少动态效果支持。

## 目标与非目标

### 目标

- 首页所有主要内容区块进入视口时统一淡入并轻微上移。
- 相册页的页面头部、文件夹网格和照片网格拥有一致的滚动入场；文件夹到照片的视图切换能够重新触发网格入场。
- 音乐浮窗挂载时进行一次即时淡入上移，不影响播放状态和唱片旋转。
- 视频、照片、资讯、积分详情弹窗打开时使用统一的即时淡入上移和轻微缩放。
- 保留现有列表和卡片的错峰效果，不把持续滚动的阵容圆柱卡片纳入会改变其布局的动画。
- `prefers-reduced-motion: reduce` 下所有内容直接可见，保留现有业务交互约束。

### 非目标

- 不引入新的动画库或页面级主题切换。
- 不改变轮播、拖拽、自动播放、音乐播放或弹窗关闭时序。
- 不为后台配置页面增加本次公开前台动画。

## 设计方案

采用“统一淡入上移 + 组件标记”的方案，沿用现有滚动观察逻辑，新增一套只负责挂载即时入场的 CSS 标记。

### 滚动入场

- 继续使用 `data-reveal` 作为需要由 `useRevealOnScroll` 观察的元素标记。
- 首页 `Hero`、`StatsBar`、`FeaturedMembers`、`GalleryPreview`、`Roster`、`Leaderboard` 和 `NewsFeed` 均保证有区块级标记。
- `AlbumPage` 的页面头部及当前显示的文件夹/照片网格使用同一标记。网格因 `activeAlbumId` 切换而重新渲染时，观察逻辑重新绑定。
- 现有成员卡、积分行和资讯项错峰继续使用 `--stagger-index`。阵容圆柱滚动模式保持现有 transform 和 opacity 逻辑，不追加会覆盖其定位的子项动画。

### 即时入场

- 新增 `data-entrance` 标记，用于不参与滚动观察、挂载即出现的公开前台模块。
- `MusicPlayer` 挂载时使用淡入上移，播放中的头像旋转规则保持不变。
- `VideoModal`、`PhotoModal`、资讯详情弹窗和 `ScoreDetailsModal` 的内容面板使用统一淡入上移并轻微缩放。背景层继续使用现有 backdrop 动画。
- 即时入场只影响出现时的视觉状态，不改变焦点管理、Escape 关闭、背景点击关闭和 `body.modal-open`。

### 动画参数与无障碍

- 区块默认从 `translateY(18px)` 到 `translateY(0)`，过渡约 520ms，使用现有缓动曲线。
- 即时内容面板使用约 280ms 的淡入、上移和轻微缩放，沿用现有 `modal-in` 节奏。
- 错峰延迟通过 CSS 自定义属性计算，并限制在短延迟范围内，避免长列表等待过久。
- `prefers-reduced-motion: reduce` 下，滚动入场和即时入场均直接设置为可见、无 transform；现有 CSS 对轮播自动切换的例外规则继续有效。

## 组件与数据流

本次只调整公开前台组件的 DOM 标记和全局 CSS：

1. React 组件在对应区块、浮窗或弹窗内容面板上添加 `data-reveal` 或 `data-entrance`。
2. `useRevealOnScroll` 继续查询 `data-reveal`，在 IntersectionObserver 不可用或减少动态效果时立即添加可见状态。
3. CSS 统一定义两类标记的初始态、可见态、错峰和减少动态效果覆盖规则。
4. 组件的业务状态、媒体加载、轮播位置和弹窗生命周期保持不变。

## 错误与边界处理

- IntersectionObserver 不可用时，所有滚动区块直接可见，不能留下透明内容。
- 页面在减少动态效果模式下加载或切换相册目录时，内容直接可见。
- 动态挂载后立即卸载的弹窗不等待动画完成，保持现有关闭行为。
- 缺少图片、视频或音乐资源时，现有占位和备用图逻辑优先，动画不改变资源错误处理。

## 测试与验收

### 自动化测试

- 首页测试断言所有主要区块存在入场标记，弹窗内容和音乐浮窗带即时入场标记。
- 相册组件测试断言文件夹视图和照片视图的入场标记随视图切换存在。
- 减少动态效果或缺少 IntersectionObserver 时，公开内容保持可见。
- 运行 `npm test -- --run` 和 `npm run build`。

### 浏览器验收

- 在 390×844、768×1024 和 1280×800 视口检查首页及相册页，确认滚动入场、视图切换和弹窗入场正常。
- 检查页面级横向溢出为 0，阵容拖拽、风采轮播、音乐播放和弹窗关闭不受影响。
- 在减少动态效果模式下检查内容立即可见，风采轮播仍按既有规则自动切换。
