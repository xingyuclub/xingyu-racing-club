# 星屿 H5 新闻二级页 + 分享 + 置顶 + 分类 Tab 设计

日期：2026-08-05
状态：已与用户确认需求，2026-08-05 已实施

## 背景与目标
当前首页 `NewsFeed` 平铺全部新闻，点开是弹窗详情，无分类、无置顶、无二级页、无分享。本次为新闻模块增加：
1. 详情页分享链接到微信群（便于发布消息）
2. `#news` 二级列表页查看更多新闻
3. 首页只显示后台置顶新闻（≤5 条），无置顶时兜底最新 3 条
4. 列表页按"公告 / 活动"等分类 Tab 切换，分类列表后台可增删
5. 独立详情页 `#news/<id>`

## 需求确认（2026-08-05 用户答复）
1. 分享形式：A —— 复制链接 + 提示去微信粘贴分享（不接 JSSDK、不做海报）
2. 暂时无公网：链接为当前地址 `origin + pathname + #news/<id>`，能否打开取决于访问网络
3. 首页置顶：只显示置顶新闻，最多 5 条；一条都没置顶时兜底显示最新 3 条
4. 分类：后台可增删分类列表；现有"活动"新闻归到"活动"Tab
5. 详情：独立详情页，不用弹窗

## 数据模型变更
- 新闻项新增 `pinned: boolean`（置顶开关），缺省 `false`
- 配置顶层新增 `newsCategories: string[]`（分类列表，后台可增删）
- 旧配置迁移（`migrateRawConfig`）：
  - 每条新闻补 `pinned: false`
  - 无 `newsCategories` 时从现有新闻 `category` 去重派生；派生为空则默认 `['公告', '活动']`
- 服务端校验（`configStore.js`）：
  - `newsCategories` 必须为字符串数组，每项非空且 trim 后唯一
  - 新闻项 `pinned` 若存在必须为布尔
  - 顶层 key 白名单加入 `newsCategories`

## 首页 NewsFeed
- 由 App 传入 `getHomeNews(siteData.news)`：
  - 置顶项按配置顺序取前 5 条
  - 无置顶 → 按日期倒序取最新 3 条（日期解析 `2026.8.1` / `2026-08-01` 两种格式，解析失败按原顺序稳定排后）
- 新闻卡片改为 `<a href="#news/<id>">` 跳详情页，移除弹窗
- 列表底部加"查看更多新闻"入口 → `#news`

## 路由（hash，沿用 #album 模式，不引入路由库）
- `#news` → `NewsPage`（列表页）
- `#news/<id>` → `NewsDetailPage`（详情页）
- `#album` → 相册页；其余 → 首页
- 音乐浮窗在所有页面保留（与相册页一致）

## NewsPage 列表页
- 头部：返回首页 + 标题"车队动态" + 新闻总数
- Tab 条：`全部` + `newsCategories` 各项（横向滚动，激活态高亮）
- 过滤：`全部` 显示全部；其余按 `category === tab` 精确匹配；未匹配任何分类的新闻只在"全部"出现
- 列表按日期倒序；空分类显示"该分类下暂无资讯"
- 点击卡片 → `#news/<id>`

## NewsDetailPage 详情页
- 头部：返回（有历史则 `history.back()`，否则回 `#news`）+ 分享按钮
- 内容：分类 / 日期 / 标题 / 封面图 / 摘要 lead / 正文（`bodyHtml` 富文本，无则 `body` 纯文本）
- 找不到 id：显示"资讯不存在或已删除" + 返回
- 分享：复制 `window.location.href`，优先 `navigator.clipboard.writeText`，降级 `execCommand('copy')`（textarea 方案）；成功 Toast"链接已复制，去微信粘贴分享吧"，失败提示手动复制

## 后台
- 新闻编辑卡片加"置顶"复选框（`NewsFields`）
- 新闻管理区顶部加"分类列表"编辑器：每行一个输入框 + 删除，底部"新增分类"按钮
- 样式：`admin.css` 增加分类行样式

## 兼容与迁移
- 旧配置无 `pinned` / `newsCategories`：读配置时自动迁移并落盘（沿用现有迁移机制）
- 旧 `body` 富文本/纯文本渲染逻辑不变
- 现有首页资讯模块测试改为断言新行为；弹窗详情相关测试改为断言详情页
