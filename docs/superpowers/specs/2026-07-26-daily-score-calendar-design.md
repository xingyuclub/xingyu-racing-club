# 星屿每日积分日历设计

## 目标

将现有积分榜入口升级为按日期查询每日积分的 H5 交互，同时保持首页其他模块、布局和已有功能不变。

## 首页积分榜

- 标题从“积分榜”改为“星屿积分榜”。
- 操作按钮文字从“查看具体分数”改为“查找”。
- 操作按钮使用用户提供的蓝色搜索图标 `/images/icons/search.png`。
- 主榜积分单位从 `PTS` 改为“分”，例如 `98分`。
- 主榜仍展示 Top 10，排序和成员数据不变。

## 日期查询弹窗

- 点击“查找”打开“日期积分查询”弹窗。
- 弹窗默认显示配置中第一条积分记录所在月份。
- 月历提供上一月、下一月切换；星期标题使用中文“日、一、二、三、四、五、六”。
- 有积分记录的日期显示状态点；当前选择日期使用蓝色选中态。
- 点击任意日期后，在月历下方展示当天结果。
- 无配置记录时显示“当日暂无积分记录”。

## 每日积分表

- 表格列按用户模板组织：队员、队内赛第一局至第三局、开黑赛第一局至第三局、得分、总分。
- H5 下表格允许横向滚动，队员列固定在左侧，避免压缩和文字重叠。
- 每日数据来自 `teamData.js` 配置，不增加后端、数据库、管理后台或自动抓取。
- 首版提供一条可替换的示例日期记录；模板截图仅用于列结构，不照录截图中的数值。

## 状态与关闭

- 弹窗支持右上角关闭、点击遮罩关闭和 Escape 关闭。
- 打开弹窗时锁定正文滚动，关闭后恢复。
- 切换月份不修改首页榜单；选择日期只影响弹窗内明细。

## 验收标准

- 首页显示“星屿积分榜”“查找”和中文积分单位。
- 搜索按钮加载用户提供的图标。
- 点击“查找”可以打开月历，点击日期可以展示明细或空状态。
- 表格在 390px 和 477px H5 视口不与其他内容重叠，不产生页面级横向溢出。
- 现有自动化测试、生产构建和 `git diff --check` 通过。
